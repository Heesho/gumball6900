# Position and exit matrix

## Reading this matrix

`PASS` means the working tree supplied a bounded public path under the stated supported-token and correctly bound graph
assumptions. It is not a claim about an unverified deployment. `OPEN` is an unsatisfied review requirement. `INTRINSIC`
means recovery necessarily depends on the asset whose transfer is the entitlement. `NO USER CLAIM` identifies protocol
yield, surplus, or donations for which no account ledger exists. Gas observations use the audit test environment; the
pinned Robinhood Chain observations reported a 32,000,000 transaction and block gas limit.

## Minimum transaction and time summary

- Known signal allocation: one transaction and no wait per Strategy. A complete portfolio takes one scalar transaction
  per known nonzero Strategy; batches are optional.
- Liquid GBX redemption: one approval if allowance is absent, then one atomic redemption containing the complete
  chosen healthy basket for that burn. There is no economically equivalent per-asset split: a one-token call is a
  bounded selective fallback that permanently forfeits the burned holder's share of every omitted asset. Fund exposes
  no bounded complete asset list, so current release-facing claims of every holding in one transaction fail CEX-09. No
  wait applies to a caller-selected healthy basket.
- Occupied Mine tenure: one replacement transaction; waiting until one hour after the tenure start makes it independent
  of USDG payment and Router behavior.
- Miner USDG claim: one transaction by any caller after the paid replacement records it.
- Healthy Bribe reward: the beneficiary can use one direct scalar transaction per token, one direct all-token Bribe
  call, or optional caller-owned Resonance batches split to fit gas; no need to claim before removing signal.
- Strategy revenue and both Router buffers are yield plumbing, not account principal exits.

The open CEX-03 discovery row is why this report does not state the unconditional permitted conclusion that no known
principal-exit blocker remains. CEX-09 separately blocks any complete-Fund-basket or guaranteed-arbitrage product claim
even though a known healthy caller-selected redemption remains bounded.
