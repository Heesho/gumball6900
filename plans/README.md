## Findings considered and rejected or deferred

- **An onchain cross-graph history registry** is not planned. It would broaden Mine or introduce another continuing
  protocol registry, conflict with ADR 0055's isolated old/new graph boundary, and require a separate user-approved
  architecture decision. Without that change, historical graph-address discovery remains an explicit residual risk.
- **An unbounded `values()` getter, `removeAll`, or a Lens-side exit loop** is rejected. Its gas grows with the account's
  portfolio and it can remove the scalar bounded-exit fallback that is the primary liveness guarantee.
- **A duplicate amount cache in Resonance** is rejected. Each paired Bribe remains the canonical per-account amount
  ledger; membership stores addresses only.
- **A single history-complete multi-graph subgraph** is deferred. The selected simpler model is one retained subgraph
  deployment per Resonance generation if a future cutover actually occurs.
- **SECURITY-01 is accepted with no remediation** under ADR 0058; no plan here changes the Strategy auction economics.
