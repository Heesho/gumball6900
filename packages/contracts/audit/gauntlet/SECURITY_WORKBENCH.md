# Security workbench

Status: active.

1. Freeze target, toolchain, dirty-tree exclusions, scope, and target delta.
2. Run cold independent source reviews before exposing reviewers to historical findings.
3. Establish complete deterministic, fuzz, invariant, integration, Hardhat, ABI, simulation, static, symbolic,
   mutation, gas, and fork baselines.
4. Build independent upstream and mathematical reference models.
5. Validate every candidate with a separate reviewer and the smallest practical executable reproduction.
6. Apply only independently confirmed minimal fixes, then obtain independent fix review.
7. Repeat fresh red-team and regression waves until every convergence condition is satisfied.

The first cold wave is partitioned into Mine/Resonance, exitability/custody/rewards, and launcher/Strategy/deployment
tracks. Reviewers were explicitly barred from prior finding records and from editing production code.
